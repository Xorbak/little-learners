# Pictures

Drop your own pictures here to replace the emoji. They're picked up automatically
(refresh the app after adding one).

- `words/<word>.png` (or .jpg, .webp, .svg): a flash-card picture, e.g. `words/cat.png`,
  `words/yoyo.png`. The file name is the word in lowercase with no spaces or dashes.
- Square, about 512 × 512, one clear object in the middle, plain or transparent background.

See the "Pictures to make" list for every word and what to draw.
