# Recordings

Drop your own voice recordings in this folder to replace the computer voice.

Name each file after the clip it replaces, for example:

| File | Says |
|---|---|
| `pop.pop-all-the.mp3` | "Pop all the" |
| `numbers.plural.3.mp3` | "threes" |
| `numbers.name.3.mp3` | "three" |

- Accepted formats: `.mp3`, `.m4a`, `.wav`, `.ogg`, `.webm`
- Refresh the app and the recording is used automatically.
- Any clip without a recording keeps using text-to-speech, so you can record a few at a time.
- The full list of clips, with what each says and which are already recorded, is in the
  parent area of the app under **Recording checklist**.

Tip: leave a tiny gap of silence at the start and end, and keep the volume similar across clips,
since phrases are stitched together from several recordings ("Pop all the" + "threes").
