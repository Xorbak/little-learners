# Sounds around us

The "What's that sound?" game makes its sounds in code. A real recording sounds
better: put a file here with one of these names and it is used instead
(mp3, m4a, wav, ogg or webm; keep it under 4 seconds):

phone, doorbell, car-horn, siren, clock, rain, drum, bike-bell, train, knock,
thunder, tap, bird, snore, kettle

e.g. `src/sounds/doorbell.mp3`. Free recordings: freesound.org or pixabay.com/sound-effects.
